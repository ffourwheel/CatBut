# Fixed button slots for cat targeting

สถานะ: accepted

เกมจะใช้ Button Slot ถาวรสูงสุด 8 ตำแหน่ง (`slot-1` ถึง `slot-8`) โดยแต่ละ Stage เปิดใช้งาน 4–8 ปุ่มจากชุดตำแหน่งที่กำหนดล่วงหน้า จำนวนคู่ใช้ชุดสมมาตร ส่วนจำนวนคี่ใช้ชุดที่ออกแบบไว้ล่วงหน้า และช่องที่ไม่ใช้งานจะแสดงเป็นโต๊ะว่างโดยไม่มีพื้นที่กด แมวจะสุ่ม Sabotage ครั้งละหนึ่ง Activated Button ต่อ Cat Event และถ้า Action ถูกเร่งจากการแตะจะยกเว้นปุ่มที่เพิ่งแตะเมื่อมีเป้าหมายอื่น ไฮไลต์เป้าหมาย 300 มิลลิวินาที, เคลื่อน Sabotage Paw 220 มิลลิวินาทีไปยังกึ่งกลางปุ่ม และกลับเข้ารูประมาณ 200 มิลลิวินาที โดยผู้เล่นยังแตะปุ่มอื่นต่อได้ ส่งเป้าหมายเป็น `slotId` เพื่อให้ Sabotage Paw เล็งไปยังตำแหน่งจริงได้ ภาพ `cat_hole_sabotage.png` ใช้เป็น reference ของท่าทาง โดยฐานรูและโต๊ะไม่หมุน และหมุนเฉพาะเลเยอร์อุ้งเท้าตามช่อง การล็อกตำแหน่งทำให้ทำ asset และแอนิเมชันเป้าหมายได้แน่นอน แม้จะแลกกับพื้นที่ยืดหยุ่นในการสุ่ม layout น้อยลง

ภาพต้นแบบจากการสร้างภาพถูกเก็บไว้ที่ `reference/cat_sabotage_slot_upper_left_concept.png` เพื่อใช้คุยทิศทางศิลป์เท่านั้น ไม่ใช่ runtime asset โดยตรง
