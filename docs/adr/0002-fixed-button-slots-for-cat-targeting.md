# Fixed button slots for cat targeting

สถานะ: accepted

เกมจะใช้ Button Slot ถาวรสูงสุด 8 ตำแหน่ง (`slot-1` ถึง `slot-8`) โดยแต่ละ Stage เปิดใช้งาน 4–8 ปุ่มจากชุดตำแหน่งที่กำหนดล่วงหน้าแบบสมมาตร และช่องที่ไม่ใช้งานจะแสดงเป็นโต๊ะว่างโดยไม่มีพื้นที่กด แมวจะสุ่ม Sabotage ครั้งละหนึ่ง Activated Button ที่ไม่ใช่ปุ่มกำลังกดต่อ Cat Event, ไฮไลต์เป้าหมายล่วงหน้า 250–400 มิลลิวินาที และส่งเป้าหมายเป็น `slotId` เพื่อให้กราฟิกอุ้งเท้าเล็งไปยังตำแหน่งจริงได้ การล็อกตำแหน่งทำให้ทำ asset และแอนิเมชันเป้าหมายได้แน่นอน แม้จะแลกกับพื้นที่ยืดหยุ่นในการสุ่ม layout น้อยลง
