# Fixed button slots for cat targeting

สถานะ: accepted

เกมจะใช้ Button Slot ถาวร 8 ตำแหน่ง (`slot-1` ถึง `slot-8`) และทุก Stage เปิดใช้งานครบทั้ง 8 ปุ่มจากชุดตำแหน่งที่กำหนดล่วงหน้า โดยไม่สุ่มจำนวนและไม่จัดเรียงตำแหน่งใหม่ แมวจะสุ่ม Sabotage ครั้งละหนึ่ง Activated Button ต่อ Cat Event และถ้า Action ถูกเร่งจากการแตะจะยกเว้นปุ่มที่เพิ่งแตะเมื่อมีเป้าหมายอื่น ไฮไลต์เป้าหมาย 160 มิลลิวินาที, หันตัวและยื่นแขนที่เชื่อมจากไหล่ 120 มิลลิวินาที, สัมผัสปุ่มที่ 80 มิลลิวินาที และกลับเข้ารูประมาณ 220 มิลลิวินาที โดยผู้เล่นยังแตะปุ่มอื่นต่อได้ ส่งเป้าหมายเป็น `slotId` เพื่อให้ Cat Reach Animation เลือกแขนและเล็งไปยังตำแหน่งจริงได้ ภาพ `cat_hole_sabotage.png` ใช้เป็น reference ของท่าทาง โดยฐานรูและโต๊ะไม่หมุน และไม่ใช้มือแยกที่ลอยจากหัว การล็อกตำแหน่งทำให้ทำ asset และแอนิเมชันเป้าหมายได้แน่นอน แม้จะแลกกับพื้นที่ยืดหยุ่นในการสุ่ม layout น้อยลง

ภาพต้นแบบจากการสร้างภาพถูกเก็บไว้ที่ `reference/cat_sabotage_slot_upper_left_concept.png` เพื่อใช้คุยทิศทางศิลป์เท่านั้น ไม่ใช่ runtime asset โดยตรง
