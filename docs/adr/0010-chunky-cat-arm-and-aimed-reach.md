# ADR 0010: ปรับสัดส่วนแขนแมวและการเล็งเป้าหมายให้เป็นธรรมชาติ

## Status

Accepted

## Context

หลังใช้ code-drawn Cat Rig (ADR 0009) พบปัญหาจากการรีวิวภาพจริง:

- แขนเล็กผิดสัดส่วนชัดเจน: เส้นแขนหนาเพียง ~23px จอ เทียบกับลำตัวกว้าง ~259px
- แขนถูกวาดไว้ "หลัง" ลำตัว (arm ก่อน body ใน catRig) และ shoulder อยู่ชิดขอบตัว ทำให้ดูเหมือนแขนลอยแยกจากตัวแมว
- สมการ reach เดิม clamp สเกลที่ 1.16 ทำให้ปุ่มด้านล่างวงแหวน (slot 4/5/6) ระยะจากไหล่ ~258-342px ไม่มีทางถึง อุ้งเท้าจึงกด "อากาศ"
- หัวและตาแทบไม่หันตามปุ่ม (headX เพียง ±18, gaze เกินกรอบดวงตา) ขัดกับ "แมวกดปุ่มรอบตัวต้องหันตาม"
- จังหวะเอื้อมหมุนและยืดพร้อมกันด้วย ease เดียว อ่านเป็นเข็มนาฬิกากวาดไป ไม่เป็นธรรมชาติ

## Decision

1. **สัดส่วนแขน**: แขนใช้ `armScale = 0.24` เท่ากับตัว (เดิม 0.12) เส้นขนหนา 300/244 art-px (หนา ~72px จอ เทียบตัว 259px) มีศอกงอเล็กน้อย เส้น outline วาดก่อนเส้นขนทั้งสองช่วง และความกว้าง outline ปลายแขนเท่ากับขนต้นแขนพอดี เพื่อให้รอยต่อศอกเนียนและแขนหุ่นสวยเมื่อหมุน
2. **จุดเชื่อมไหล่**: shoulder ขยับเข้าใน (`{x: 64, y: -46}`) ให้แผ่นขนไหล่ (วาดแบบไม่มีเส้นขอบตัวเอง) ทับลำตัวเสมอ และเรียง layer ใหม่เป็น body → arms → head เพื่อให้แขนอยู่ "หน้า" ลำตัวแต่หลังหัว
3. **การเล็ง**: ทั้งตัวหันตามปุ่ม หัวเอียงนำ (`headRotation` รวม `side*0.34`) และดวงตานำหัว (gaze tween เร็วกว่าหัว) ด้วย offset ที่คุมอยู่ในกรอบนัยน์ตา (±17, ±13) แขนที่ไม่ได้ใช้ห้อยลงแนบอก (tuckAngle = π/2 ± 0.35, scale 0.72) แทนท่าพักเดิมที่ชี้ไปด้านข้าง
4. **ระยะเอื้อม**: solve reach แบบสองช่วง — ถ้าระยะเกิน comfort (`REACH_SCALE_MAX = 1.24`) ลำตัวจะเอนเข้าหาปุ่มเพิ่มสูงสุด 58px (adaptive lunge) แล้ว solve ใหม่ ทำให้อุ้งเท้าลงกึ่งกลางปุ่มทุก slot (test คุมไว้ ≤ 12px)
5. **จังหวะ**: ช่วง preview ให้เท้าแตะปุ่มแล้ว (reachProgress = 1 ตั้งแต่ตอนเล็ง) จังหวะ sabotage เป็นแค่การบีบกดตามทิศ shoulder→button (`pressUnit`) และหมุนนำ-ยืดตาม (rotation tween 70% แรก) แขนอีกข้างคง alpha 0.85 เพื่อให้เห็นเป็นแมวสี่ขา

## Consequences

- ทุก slot ทั้งแปดมีอุ้งเท้าลง "บน" ปุ่มตามตัวเลขจริง ไม่ใช่แค่ใกล้เคียง ตรวจด้วย `tests/cat-reach-animation.test.mjs`
- ตัวเลขใน `CAT_RIG_GEOMETRY` เปลี่ยน (armScale 0.24, shoulder, restVector 148.8/168) ทั้ง vector preview และ raster fallback ใช้ contract เดิมร่วมกัน จึงต้องอัปเดตภาพ raster ตามสัดส่วนนี้เมื่อทำ art pass
- อุ้งเท้าถูกวาด "ใต้" ปุ่ม (button layer depth 40 สูงกว่า rig) ซึ่งอ่านได้ว่าแมวกดปุ่ม แต่ตอนทำ art pass อาจพิจารณายกแขน active ขึ้นเหนือปุ่มชั่วขณะ
- หน้า `dev/cat-rig-preview.html` เปิดใช้ตรวจท่าแบบ deterministic (`aim/press/hold/state`) โดยไม่ต้องรอจังหวะเกมจริง
