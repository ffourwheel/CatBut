# Autonomous trolling cat actions

สถานะ: accepted

Cat Action จะเกิดจาก Cat Event ที่เริ่มด้วย Timer แบบสุ่มเป็นหลัก ไม่ผูกกับการแตะปุ่มทุกครั้ง เพื่อให้เกมมีจังหวะกวนและคาดเดายากขึ้น โดย Prototype มี Action จริงเพียงสองแบบคือ WATCH และ SABOTAGE ไม่มี Fake Action หรือการสลับเป้าหมายกลางแอนิเมชัน ช่วงเวลาพื้นฐานอยู่ที่ประมาณ 500–850 มิลลิวินาทีใน Normal และมีช่วงพักขั้นต่ำ 500 มิลลิวินาทีระหว่าง Event; จังหวะ Sabotage ถูกลดให้ตอบโต้เร็วขึ้นตาม preset

การเปิดปุ่มสำเร็จมี Tap Pressure 40% ที่สามารถเร่ง SABOTAGE ได้ แต่ไม่เกิดทุกครั้ง อย่างไรก็ตามการแตะ 2 ครั้งภายใน 500 มิลลิวินาทีจะเร่ง SABOTAGE แน่นอน เพื่อกันการชนะด้วยการกดรัว การเลือกเป้าหมายยังคงใช้ Activated Button ที่มีอยู่จริง และเมื่อ Cat Action ใดกำลังทำงานอยู่จะไม่ซ้อนแอนิเมชัน หากมี Action ที่ถูกเร่งเข้ามาระหว่าง WARNING, PEEK, WATCH, ATTACK, SABOTAGE หรือ HIDE ให้รอคิวได้หนึ่ง Action และเริ่มหลัง Action ปัจจุบันจบพร้อมช่วงพัก 500 มิลลิวินาที

WATCH ยังคงมี Warning ก่อนเสมอ และการแตะระหว่าง WATCH จึงจะทำให้เสียหัวใจ เพื่อให้ความปั่นเกิดจากจังหวะและความถี่ของแมว ไม่ใช่ความเสียหายแบบไม่มีสัญญาณเตือน
