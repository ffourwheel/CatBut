# Cat Mood and readable pressure

สถานะ: accepted

## Context

การเร่ง Cat Event จาก Progress อย่างเดียวทำให้เกมป้องกันการกดรัวได้ไม่ชัดเจน และการเพิ่ม Mood จากทุกการเปิดปุ่มทำให้ผู้เล่นแยกเหตุและผลได้ยากว่าแมวโกรธเพราะอะไร

## Decision

Cat Mood จะเพิ่มเฉพาะเมื่อเกิด Rapid Tap ครั้งละ 25 หน่วย แบ่งเป็นสี่ระดับ:

| ระดับ | ค่า | ตัวคูณระยะรอ Cat Event |
| --- | ---: | ---: |
| ง่วง | 0–24 | 1.00 |
| สนใจ | 25–49 | 0.85 |
| หงุดหงิด | 50–74 | 0.70 |
| โมโห | 75–100 | 0.55 |

หลังไม่มี Rapid Tap 2 วินาที Mood จะลดลงหนึ่งระดับทุก 1.5 วินาที โดยต้องรักษา overshoot ของ timer เพื่อให้ผลไม่ขึ้นกับ frame rate
การลดหนึ่งระดับจะย้ายค่าไปยังจุดเริ่มต้นของระดับก่อนหน้า (เช่น โมโห 100 → หงุดหงิด 50) เพื่อไม่ให้ค่าบนขอบ 75 ยังคงเร่งความเร็วระดับโมโหอยู่

Mood มีผลต่อระยะรอ Cat Event เท่านั้น ไม่เปลี่ยนโอกาสเลือก WATCH หรือ SABOTAGE โดยตรง ส่วน Rapid Tap ยังคงบังคับ Sabotage ตามกติกา Anti-Mash

Mood จะแสดงทั้งใน HUD และบนตัวแมวด้วย label, สี และสัญลักษณ์ที่ไม่พึ่งสีเพียงอย่างเดียว เพื่อให้ผู้เล่นคาดการณ์ได้ว่าแมวกำลังอยู่ระดับใด

## Consequences

- ผู้เล่นเข้าใจเหตุผลของความถี่แมวได้จากพฤติกรรมของตนเอง
- Progress และ Mood มีหน้าที่แยกกัน: Progress กดดันตามความคืบหน้า ส่วน Mood ตอบสนองต่อ Rapid Tap
- ต้องมีช่วงพักขั้นต่ำ 500 มิลลิวินาทีเพื่อไม่ให้ Progress และ Mood คูณกันจนอ่านเหตุการณ์ไม่ทัน
- Cat Animation ต้องรองรับ Mood overlay โดยไม่รบกวน Cat State และ Cat Reach Animation
