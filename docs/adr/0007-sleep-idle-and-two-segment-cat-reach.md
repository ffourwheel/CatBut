# Visible Sleep Idle and Two-Segment Cat Reach

Status: accepted

ระหว่างไม่มี Cat Action แมวต้องยังมองเห็นและหลับอยู่ใน Hole จึงให้ gameplay state `HIDDEN` ใช้ภาพ `Sleep Idle` เป็น presentation แทนการซ่อนโปร่งใส ส่วน Sabotage ใช้ gaze overlay ที่นำสายตา แล้วขับ Cat Reach Chain แบบสองข้อต่อ (ไหล่–ต้นแขน–ศอก–ท่อนแขน/อุ้งเท้า) โดยให้ลำตัวบังรอยต่อไหล่และให้เฉพาะแขนด้านใกล้เป้าเอื้อมออก การตัดสินใจนี้เลือกความต่อเนื่องของ silhouette และความอ่านง่ายของการกระทำเหนือการใช้แขนชิ้นเดียวที่แม้เรียบง่ายกว่าแต่ทำให้แขนดูหลุดจากลำตัว
